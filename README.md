# Match Cats — React + Tailwind starter

A responsive pixel-inspired UI prototype for Match Cats. It includes:
- Home screen
- Demo game screen with interactive draw button
- How to Play screen
- Cat collection screen
- Responsive mobile layout

## Run locally

You need Node.js 18+.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Notes

- The current opponent and card outcomes are local demo logic, not online multiplayer.
- The UI uses emoji and CSS-drawn pixel cat art as placeholders. Swap these with original pixel-art assets later.
- This is a frontend starter; there is no backend, login, database, or real matchmaking yet.
